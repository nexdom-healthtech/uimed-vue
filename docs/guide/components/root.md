# Root

Componente destinado a raiz do projeto.
Responsável por carregar os estilos necessários para os demais componentes.

## Uso

<demo>
<Root>
  <h2>Testando...</h2>
</Root>
</demo>

```vue
<template>
  <Root>
    <h2>Testando...</h2>
  </Root>
</template>

<script lang="ts" setup>
import { Root } from "@nexdom/uimed-vue/components";
</script>
```
