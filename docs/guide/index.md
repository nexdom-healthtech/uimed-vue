# O que é uimed-vue?

É um framework de UI [Vuejs](https://vuejs.org/) com diversos componentes e funções reutilizáveis entre eles (_components_ e _composables_).

## Casos de uso

### Componentes

Recursos reutilizáveis para elaboração de interface gráfica.

#### Layout

| Componente                           | Descrição                       |
| ------------------------------------ | ------------------------------- |
| [Btn](./components/btn)              | Componente de botão.            |
| [Root](./components/root)            | Componente raiz.                |
| [TextField](./components/text-field) | Componente para campo de texto. |
